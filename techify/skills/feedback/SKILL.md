# Feedback

- Bugs and feature requests for the plugin or the MCP server: open an issue at https://github.com/Uliasti-Agency/techify-agent-plugins/issues or email hello@techify.work.
- Account, billing or job questions: hello@techify.work.

When you help the user write a report, include: the tool name, the arguments without personal data or tokens, the error text, the time, and the workspace name. Never include tokens, candidate data or other people's email addresses.

Do not claim you contacted support. Give the user the text and the address.
